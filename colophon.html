How this site
was built

Design
Design tool
Figma — wireframes, component library, and all UI decisions
Typography
Syne (display headings) and DM Sans (body text) — both served via Google Fonts
Colour palette
Deep navy backgrounds (#080c10 → #111820), teal accent (#0EB5A0), cyan (#06b6d4). Contrast ratios checked at WCAG AA throughout
Inspiration
Dark editorial portfolios, Brutalist typography, and the intentional minimalism of tools like Linear and Vercel
Technology
Stack
Pure HTML, CSS and vanilla JavaScript — no frameworks, no build steps, no dependencies. Every line written by hand
Hosting
GitHub Pages — free, fast, and tied directly to the master branch. Deploys on every push
Domain
sampannadhungel.com.np — registered via Mercantile Nepal (.com.np TLD)
Forms
Formspree — handles contact form and newsletter submissions
View counts
CountAPI — lightweight hit counter on project and blog pages
Analytics
None. No tracking scripts, no cookies, no third-party data collection
Performance
Images
All portfolio images lazy-loaded. SVG thumbnails used where appropriate (no raster waste)
Fonts
Preconnect hints + display=swap to prevent FOIT
CSS
Single stylesheet (~35 KB unminified). No utility frameworks
Lighthouse
Performance 92+ · Accessibility 96+ · Best Practices 100 · SEO 100
Features
Easter eggs
Three HTML source clues leading to /secret.html. Konami code (↑↑↓↓←→←→BA) triggers confetti. See if you can find them all
⌘K palette
Press Ctrl+K or ⌘K from anywhere to jump to any page, project or section
Weather
Hero background shows live weather particles based on your location (with graceful fallback)
Cursor
Custom magnetic cursor with context-aware trail on desktop
This site is hand-coded with care. If you spot a bug, have a suggestion, or just want to say something about the design — get in touch.
